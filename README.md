## Local dashboard

For manual startup, first run `nvm use` to select the existing `.nvmrc` pin (Node 22.22.0), then run `npm run dev` and open <http://127.0.0.1:5173/> (or <http://localhost:5173/>). The dev server uses port 5173 with strict port checking; it reports an occupied port instead of silently moving to 5174. If a server already owns 5173, use that running dashboard or stop that server before starting another one. Node 18 is not supported by this Vite version; a terminal that has not selected the project Node version can otherwise fail with `crypto.hash is not a function`.

On this Mac, the existing `com.deltablock.liquidityiq.dashboard` LaunchAgent starts the dashboard at login and keeps it running on 5173. A second manual `npm run dev` is normally unnecessary. Its logs are in `~/Library/Logs/LiquidityIQ_Reports/dashboard.stdout.log` and `dashboard.stderr.log`.

`src/data/reportsIndex.ts` is application code required by both pages; keep it when removing generated report files. The index discovers available report files and imports only the report selected by its URL. A small `reportsMetadata.json` supplies company names and catalog fields. `npm run dev` and `npm run build` refresh this metadata automatically; `npm run reports:metadata` refreshes it while an existing server is running. Newly added report files remain accessible before that refresh, with filename-based catalog labels.

## News & Events tab

Reports generated after 6 October 2026 carry `REPORT_DATA.news` (one year of
close, volume and the issuer's publications as stars, built by the news module of
the Reports pipeline). `src/sections/NewsEventStudy.tsx` renders it in the
**News & Events** tab (formerly the empty Sentiment tab): click a star for the
reading, cited figures, relative size, market response J-1/J0/J+1 and the issuer's
history for that category. Reports without the block keep a placeholder.
Since 7 October 2026 both files carry real ClickHouse bars (regenerated by
`main.py`); the synthetic previews are kept in `src/data/.news-preview-backup/`.

Chart contract `news-annual-chart.v2` (7 October): one marker per *event* —
publications of the same session and category are merged (`publications`,
`publication_count`), thread follow-ups are drawn as small dashed markers linked
to their origin (`thread_role`, `thread_origin`, `thread_events`, "Thread
follow-ups" toggle); the rebased index always stays inside the frame and a right
axis shows the % change since the first close for both lines; the popup is
clamped inside the chart box and scrolls when taller. `v1` data still renders.

Method v2 (7 October, night): market responses carry *ranks in the issuer's own
history* (`abs_return_rank`, `volume_ratio_rank`, shown as "top 7%"; labels
`notable` = top 10%, `strong` = top 2.5%), the pre-announcement window carries
`cumulative_move_rank`, `mean_volume_ratio_rank`, `notable` ("worth noting",
top 10%), `unusual_activity` (top 5%) and `base_rate_in_history`; events may carry
`implication` (the model's shareholder implication from `news-analysis.v2`:
label, basis, rationale, confidence — shown as a badge and used for the marker
colour when the direction is indeterminate) and `holding_change`; level-1 dots
include director-disposal bursts (`subtype: director_disposal_series`); counts
add `thread_follow_up_dots` and `insider_bursts`. Category `operations` added.

Reading v3 (8 October): levels are no longer displayed. Events carry the
model's reading (`headline`, `category_label`, `price_relevance` = "could move
the price: likely / possible / unlikely / none" with horizon, `dated_facts` and
`insider_transaction` with the cited day's own session), every non-routine
publication is a star (hollow when not read yet) and formalities are dots
(`news-annual-chart.v3`). Each star may carry `event_study`
(`news-event-study.v1`): when the trades and depth rows of its session are stored
in ClickHouse, the popup shows an intraday event study — t0 on the SGX continuous
clock, a per-minute chart (mid vs t0 in bp, spread, buyer/seller volume) and the
−120/−30/−5/+5/+30/+60 trading-minute windows (trades, volume, signed imbalance,
mid return, time-weighted spread, top-5 depth); otherwise the exact reason
(`session_not_in_base`, …). `report.news.annual_chart.intraday_coverage` lists
the sessions requested and covered. Types: `NewsEventStudyData`,
`NewsEventStudyWindow`, `NewsEventStudyPoint` in `src/types/report.ts`.

The report catalog now uses lazy imports. Opening the dashboard or one report no longer imports every report payload. Production builds still include the available reports as separate chunks.
